# Security policy

Report potential vulnerabilities using Mervoq's [private reporting channel](https://github.com/mervoq/.github/security/advisories/new). Private vulnerability reporting is enabled for this repository.

Include the affected project, version or commit, impact, and safe reproduction steps. Do not open a public issue or include live credentials or customer data. If the reporting channel is unavailable, use an existing private contact channel with the project maintainer; no public business email has been approved.

Product-specific policies take precedence. Support periods and response commitments are defined by each product when releases become available.
