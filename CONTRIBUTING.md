# Contributing to Mervoq projects

Follow each product repository's contribution instructions first. Use a feature branch, open a focused pull request, explain the problem and outcome, and request review from an authorized maintainer.

Document validation actually performed and any remaining gaps. Do not include credentials, customer data, or production database exports. Preserve third-party licenses, copyright notices, and attribution.

Use English for public documentation. Do not change repository visibility, ownership, collaborator access, or application permissions without authorization. See SECURITY.md for private vulnerability reporting.
